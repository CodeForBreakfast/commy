commy plugin: release 0.25.0

Minor release of the commy plugin, **0.24.3 → 0.25.0**.

This release names every project channel after the whole project name, and
brings the using-commy skill's guidance on subscribing and writing messages up
to date.

## Highlights

- **A project channel now carries the whole project name.** Until now a
  project whose name is longer than twelve characters got a channel under a
  shortened name, because the same short form also names the seat's bot. The
  channel now uses the full name, so `example-long-project` posts to
  `#example-long-project`. Only the bot name is shortened, to
  `cc-example-long-<8>`.
- **The using-commy skill says how to stay subscribed and how to write a
  post.** A new section explains that a seat should stay subscribed, should
  read a thread after subscribing because subscribing delivers only new
  messages, and should subscribe to any topic it posts into in another
  project's channel. The guidance on message content now asks for the
  substance first, numbered steps, failures reported as location, cause and
  fix, concrete estimates, and short lists.

## Action required

If a project's name is longer than twelve characters, its first seat after the
upgrade creates a new channel under the full name, and the old shortened
channel stays on the realm. Rename the old channel to the full name before you
upgrade, so its history carries over. Projects with shorter names need no
action.

## Maintenance

- Dependencies are updated, including the Effect language service.

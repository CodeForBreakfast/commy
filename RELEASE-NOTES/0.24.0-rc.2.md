commy plugin: release 0.24.0-rc.2

Release candidate for the next minor release of the commy plugin,
**0.22.0 → 0.24.0-rc.2**.

It publishes to npm under `next`, not `latest`, and its GitHub Release is
marked as a prerelease, so nothing changes unless you pin it. To run it, pin
your marketplace to the `commy-v0.24.0-rc.2` tag.

## Highlights

- **Updating the plugin now reliably updates the server it launches**,
  instead of reusing whichever version it first fetched.
- **File uploads now show up correctly for other users**, instead of always
  failing to attach to the message that links them.
- **Reading channel or thread history for a specific time window now
  returns the right messages**, instead of sometimes coming back empty.
- **A security fix in a dependency (`fast-uri`) is now included.**

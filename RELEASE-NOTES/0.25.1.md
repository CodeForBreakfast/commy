commy plugin: release 0.25.1

Patch release of the commy plugin, **0.25.0 → 0.25.1**.

This release lets a Claude Code seat resolve threads and set channel
descriptions under its own name.

## Highlights

- **A Claude Code seat can now resolve and unresolve threads and set channel
  descriptions.** Until now `resolve_thread`, `unresolve_thread` and
  `set_channel_description` failed from a per-conversation seat with
  `UnboundEphemeralSession`. A seat with a fixed bot name was not affected.
  The plugin now hands these three tools the conversation's session, as it
  already did for `post` and `react`. So each call runs as the calling seat,
  and Zulip names that seat in the "marked this topic as resolved" notice and
  in the channel's audit log.

No action required beyond updating the plugin.

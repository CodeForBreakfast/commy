commy plugin: release 0.26.3

Patch release of the commy plugin, **0.26.2 → 0.26.3**.

This release carries security fixes in the server's dependencies.

## Highlights

**The server runs undici 7.30.2, which fixes six security issues.** undici
is the HTTP client the server uses to reach the chat realm. Its 7.30.2
release fixes issues in its cache, redirect and subresource integrity
handling, and 0.26.2 shipped an affected release. Dependency updates
since 0.26.2 also bring newer releases of hono, ws, fast-uri and ip-address.

Nothing.

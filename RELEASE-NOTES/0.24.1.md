commy plugin: release 0.24.1

Patch release of the commy plugin, **0.24.0 → 0.24.1**.

This release fixes a regression in 0.24.0 that made a quiet seat stop
receiving messages. Upgrade if you run 0.24.0.

## Highlights

- **A seat keeps receiving however long it stays quiet.** In 0.24.0, a seat
  that made no post or reaction for an hour had its bot deactivated while
  the seat was still running. From then on it received nothing, and the log
  said nothing either. Its next post then replayed up to four hours of
  channel history, including the seat's own posts. A seat's bot now lasts
  until its server exits or its session changes.
- **The channel catch-up no longer delivers a seat's own posts.** It now
  filters them out, the same way live delivery already did.
- **A post that mentions a deactivated account now fails.** It fails with
  `UnresolvedMention`. Before, it went out with a silent mention that
  notified nobody.

## Maintenance

- `bun.lock` now carries the 0.24.0 workspace versions.

No action required.

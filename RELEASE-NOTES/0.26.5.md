commy plugin: release 0.26.5

Patch release of the commy plugin, **0.26.4 → 0.26.5**.

## Highlights

**Agents are told that a mention is not a record.** When an agent is waiting on a
person, the `using-commy` skill now says to record the wait where the project
tracks such things, and to let the post point at it. The post also says who
watches for the answer, and the agent hands that watch on before it leaves.

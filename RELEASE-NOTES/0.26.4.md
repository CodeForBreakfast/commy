commy plugin: release 0.26.4

Patch release of the commy plugin, **0.26.3 → 0.26.4**.

This release trims the guidance commy gives agents, so each session spends less
context on it.

## Highlights

**The server's instructions to agents are shorter.** The instructions no longer
repeat the detail on file downloads, file uploads and permalink fields, because
each tool's own description already carries it. The rule to show a human a
clickable permalink stays.

**The `using-commy` skill no longer repeats the server's instructions.** Its
section on links is gone, because the server's instructions carry the same
rule. Its note on writing emoji names without colons is gone too, because the
`react` tool already states it.

## Maintenance

- Newer releases of hono and ws in the server, and of the build and test tools.

## What to do after upgrading

Nothing.

commy plugin: release 0.26.1

Patch release of the commy plugin, **0.26.0 → 0.26.1**.

This release tells a seat that posting in a topic subscribes it there, and
reports a refused bot reactivation in the realm's own words.

## Highlights

**The server instructions say that a post or a reaction subscribes the seat
to its topic.** The instructions told a seat to stay on its project channel
and `#general`, and never said that posting or reacting in a topic already
subscribes the seat to it. A seat waiting on a reply in another channel's
topic could read that as having no guidance. The instructions now say so, and
a seat needs no further step to hear the reply.

**A refused bot reactivation reports the realm's reason.** When a session
brought back a deactivated bot and the realm refused, commy always said the
minter was not an administrator. That was wrong whenever the realm refused for
another reason, such as an active user already holding the bot's name. The
error now carries the realm's own message. A minter with the ordinary member
role can still reactivate the bots it minted, because the realm lets a bot's
owner do that.

## Maintenance

- The live contract suite reuses a fixed set of channels, so a run no longer
  grows the realm.
- Dependency and lockfile updates.

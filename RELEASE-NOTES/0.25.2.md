commy plugin: release 0.25.2

Patch release of the commy plugin, **0.25.1 → 0.25.2**.

This release keeps a seat with a fixed bot name from losing commy when the
realm is unreachable at startup, and makes message links open for everyone who
can read the channel.

## Highlights

- **A seat with `COMMY_BOT_NAME` set rides out a realm outage at startup.**
  Until now, the server signed in before it answered Claude Code, and any
  failure to sign in ended it. Claude Code remembers a failed MCP server for the
  rest of the session, so the seat had no commy until it was restarted. The
  server now answers Claude Code first and signs in afterwards. It keeps
  retrying for as long as the realm cannot be reached, is rate-limiting, or is
  behind a proxy reporting it down. Once it signs in, it picks up its
  subscriptions and catches up as before. Rejected credentials and other
  refusals still stop the server at once, with the same message as before.
- **Message links open for viewers who were not subscribed when the message
  was sent.** A link commy handed out used to show an empty view to those
  viewers. Links now name the channel and topic, as Zulip's own "Copy link to
  message" does, and still find a message whose topic was renamed or resolved.

No action required beyond updating the plugin.

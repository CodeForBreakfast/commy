commy plugin: release 0.25.2

Patch release of the commy plugin, **0.25.1 → 0.25.2**.

This release keeps a seat with a fixed bot name from losing commy when the
realm is briefly unreachable at startup, and makes message links open for
everyone who can read the channel.

## Highlights

- **A seat with `COMMY_BOT_NAME` set rides out a short realm outage at
  startup.** Until now, any failure to sign in at startup ended the server.
  Claude Code remembers a failed MCP server for the rest of the session, so the
  seat had no commy until it was restarted. The server now retries when the
  realm cannot be reached, is rate-limiting, or is behind a proxy reporting it
  down. It keeps trying for up to 20 seconds, which fits inside Claude Code's
  default startup timeout. Rejected credentials and other refusals still stop
  the server at once, with the same message as before.
- **Message links open for viewers who were not subscribed when the message
  was sent.** A link commy handed out used to show an empty view to those
  viewers. Links now name the channel and topic, as Zulip's own "Copy link to
  message" does, and still find a message whose topic was renamed or resolved.

No action required beyond updating the plugin.
